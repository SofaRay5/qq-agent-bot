## 3. LLM 回复 MVP

- [x] 独立的 LangChain/DeepSeek 回复模块：固定 `deepseek-flash`，单轮文本输入；假模型测试通过，未调用付费 API。
- [x] 将消息转换为纯文本，由 `core/` 串联适配层与 `agent/`；本地假服务测试通过。
- [x] 接入 DeepSeek 并替换 echo 回复：代码、本地测试和真实 QQ 回复均已验收。超时或模型失败时发送固定提示。
- [x] 群聊只响应 @ 消息，并限制重复回复；本地测试确认日志不含测试密钥或消息正文。

完成标准：QQ 消息得到真实 LLM 回复，异常时不中断后续对话。发布前用假服务完成自动化闭环测试。
