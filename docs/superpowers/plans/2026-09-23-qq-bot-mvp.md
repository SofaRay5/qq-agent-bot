## Review Focus

1. An action result can arrive between heartbeat and message events or out of order; its `echo` must resolve only the matching waiter (Task 1 test).
2. Bad JSON, a JSON list, or an incomplete known event must be skipped without ending the receive loop (Task 2 test).
3. A group message with `at.qq` as integer, `@all`, or text before the bot mention must follow the exact trigger and extraction rule (Task 3 test).
4. A `status: failed` action response must fail the send even when a response arrived (Task 2 test).
5. An empty or non-text model answer must trigger the fixed failure reply rather than sending a blank QQ message (Tasks 5 and 6 tests).

- [x] **Step 3: Implement the smallest conversion and router.** The adapter converts only array-form `text` and `at` segments. Core ignores heartbeat/unknown events; compares `user_id` and `self_id`; remembers admitted IDs in an insertion-ordered dict capped at 1024; creates and tracks one task per admitted message. Each task waits at most 30 seconds for `reply(text)`, then calls the matching send method.
```python
def text_for_reply(event: PrivateMessageEvent | GroupMessageEvent) -> str | None:
    start = 0
    if isinstance(event, GroupMessageEvent):
        for index, segment in enumerate(event.message):
            data = segment.get("data")
            if segment.get("type") == "at" and isinstance(data, dict) and str(data.get("qq")) == str(event.self_id):
                start = index + 1
                break
        else:
            return None
    parts = []
    for segment in event.message[start:]:
        data = segment.get("data")
        if segment.get("type") == "text" and isinstance(data, dict) and isinstance(data.get("text"), str):
            parts.append(data["text"])
    text = "".join(parts).strip()
    return text or None

async def echo_reply(text: str) -> str:
    return text

task = asyncio.create_task(self._process(event, text))
self._tasks.add(task)
task.add_done_callback(self._tasks.discard)

try:
    answer = await asyncio.wait_for(self.reply(text), timeout=30)
except Exception as exc:
    logger.error("reply failed: %s", type(exc).__name__)
    answer = "暂时无法回复，请稍后再试"
try:
    await self._send(event, answer)
except (ConnectionError, TimeoutError, OneBotActionError) as exc:
    logger.error("send failed: %s", type(exc).__name__)
```
